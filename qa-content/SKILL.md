# Content QA

The goal is to answer one question with evidence: **is everything the visitor reads final, correct and consistent?** On websites generated from Figma with AI it is very common for filler text from the design to slip through ("Lorem ipsum", "Your text here"), leftovers from the Next template ("To get started, edit the page.tsx file"), English copy from the generator, Titles With Every Word Capitalized, one phone number in the footer and a different one on the contact page, and a © from two years ago. A single lorem ipsum in production costs more credibility than any technical bug.

The audited websites are in Spanish (Spain): the checks below apply Spanish spelling, typography and capitalization rules, and the regexes and word lists in the scripts match Spanish text.

**By default no code or text is modified.** Deliver the report and fix only if the user asks; new texts are approved by the client. The tools go in `/tmp/qa-content/`, never in the project.

Out of scope: titles and meta descriptions (`qa-technical-seo`), alt text from the accessibility point of view (`qa-accessibility`), legal texts (`qa-legal-spain`). Here alt is reviewed as content: it should say something meaningful and be in Spanish.

## Step 0. Context

Ask or find out:

1. **Language(s) of the website** and whether there is i18n (`app/[lang]`, `next-intl`, JSON dictionaries). Review each language separately.
2. **Source of truth for the copy**: approved document, Figma or CMS. Without it, tone findings are suggestions.
3. **Official contact details**: phone, email, address, opening hours and social networks. They are the reference for step 3.
4. **Brand terms and proper nouns** (company, products, clients) for the spell checker allowlist.
5. **Form of address**: *tú* (informal "you") or *usted* (formal "you"). It must be the same across the whole website.
6. **Where the text lives**: in the components, in a CMS or in JSON. It determines where it gets fixed.
7. **ripgrep**: the commands use `rg`. If it is not installed (`rg --version`), `brew install ripgrep` or replace `rg --files …` with `git ls-files -co --exclude-standard` and `rg -n` with `grep -rnE`.

## Step 2. Search in the code

Find filler text also where the browser does not show it (empty states, error messages, unlinked pages):

```bash
rg -n -i --glob '!node_modules' --glob '!.next' \
  -e 'lorem|ipsum|dolor sit|texto de (relleno|ejemplo|prueba)|your (text|title) here|sample text' \
  -e 'Create Next App|Generated by create next app|Get started by editing|To get started|Deploy Now|example\.com|John Doe|Acme' \
  app src components content messages locales lib 2>/dev/null
rg -n --glob '!node_modules' --glob '!.next' -e '\b(TODO|FIXME|TBD)\b' app src components content messages locales lib 2>/dev/null   # no -i: "todo" is a Spanish word ("all")
rg -n --glob '!node_modules' -e '©\s*20\d\d|20(1\d|2[0-5])' app components src 2>/dev/null   # hand-written years
ls public/ public/**/ 2>/dev/null | rg -i 'shutterstock|istock|getty|adobestock|freepik|unsplash|pexels|depositphotos|dreamstime'
```

Ignore `TODO`s in code comments that never reach the user (they belong to `qa-code-optimization`); what matters are the ones inside JSX, JSON or Markdown.

## Step 3. Extracting the visible text and automatic detection

The script visits each route with Chromium, saves the visible text of each page to a `.txt` file (for the spell checker) and looks for problems. Use the route list from `qa-functionality` or the one from `app/**/page.*`.

```bash
cd /tmp/qa-content
node extract-content.mjs http://localhost:3000 / /servicios /contacto /aviso-legal --out=out --ignore-words=Acme
```

`extract-content.mjs`:

```js
// extract-content.mjs: extracts the visible text of each route with Playwright and detects placeholders, template leftovers,
// leftover English, declared vs actual language, capitals in headings, "click aquí" links, meaningless alt, copyright year,
// stock-library images and contact details that are inconsistent across pages.
// Usage: node extract-content.mjs <baseUrl> <route> [<route>...] [--out=content] [--ignore-words=Nacar,Figma]
//   Writes <out>/<route>.txt (text per page, for the spell checker) and <out>/content.json (data + findings).
// The regexes and word lists match Spanish (and English) text on the audited site.
import { chromium } from 'playwright';
import { mkdirSync, writeFileSync } from 'node:fs';

const args = process.argv.slice(2), base = args[0];
const opt = Object.fromEntries(args.filter(a => a.startsWith('--')).map(a => { const [k, v = ''] = a.slice(2).split('='); return [k, v]; }));
const routes = args.slice(1).filter(a => !a.startsWith('--')), OUT = opt.out || 'content', YEAR = new Date().getFullYear();
mkdirSync(OUT, { recursive: true });

const PLACEHOLDER = /\b(lorem|ipsum|dolor sit amet|consectetur adipiscing|texto de (relleno|ejemplo|prueba)|your (text|title|company|name) here|insert (text|image|title)|sample text|placeholder|t[ií]tulo aqu[ií]|texto aqu[ií]|John Doe|Jane Doe|Acme( Inc| Corp)?|tu@(email|correo)|example\.com|undefined|\[object Object\]|\{\{[^}]*\}\}|000 ?000 ?000|123 ?456 ?789)\b/i;
const TEMPLATE = /Create Next App|Generated by create next app|Get started by editing|To get started, edit|Deploy Now|Vercel logomark|Learning center|Head over to Templates|Built with v0|Made (with|in) Framer|Edit with Lovable|bolt\.new|Powered by Vercel|Next\.js logo/i;
const EN = new Set('the and of to in for with on your our you we is are this that from by be at as it or more about get started learn here now read click us contact all new'.split(' '));
const ES = new Set('el la los las de del y en para con por un una que es son nuestro nuestra su sus al lo se más sobre tu te nos como'.split(' '));
const GENERIC_LINK = /^(haz |hacer )?(click|clic|pincha|pulsa) aqu[ií]\.?$|^aqu[ií]\.?$|^(leer|ver|saber) más\.?$|^más (info|información)\.?$|^(click )?here$|^read more$|^learn more$|^more$/i;
const GENERIC_ALT = /^(imagen|image|img|foto|photo|picture|icono|icon|logo|banner|gráfico|graphic|untitled|sin título|alt|null|undefined)( ?\d+)?$/i;
const STOCK = /unsplash\.com|pexels\.com|pixabay\.com|shutterstock|istockphoto|gettyimages|freepik|stock\.adobe|depositphotos|dreamstime|123rf/i;
const ignoreWords = new Set((opt['ignore-words'] || '').split(',').filter(Boolean).map(w => w.toLowerCase()));
const lang = t => { const w = t.toLowerCase().match(/[a-záéíóúñü]+/g) || []; let en = 0, es = 0; for (const x of w) { if (EN.has(x)) en++; if (ES.has(x)) es++; } return { en, es, n: w.length }; };
const findings = [], contact = { phones: {}, emails: {}, addresses: {} };
const add = (sev, type, page, evidence, detail) => findings.push({ sev, type, page, evidence: String(evidence).slice(0, 140), detail });
const note = (bucket, value, page) => { (contact[bucket][value] ||= new Set()).add(page); };

const browser = await chromium.launch(), page = await browser.newPage({ locale: 'es-ES', viewport: { width: 1366, height: 900 } });
for (const route of routes) {
  const url = new URL(route, base).href;
  try { await page.goto(url, { waitUntil: 'networkidle', timeout: 30000 }); } catch (e) { add('High', 'page-not-loading', route, e.message.split('\n')[0]); continue; }
  const d = await page.evaluate(() => {
    const vis = el => { const r = el.getBoundingClientRect(), cs = getComputedStyle(el); return r.width > 0 && r.height > 0 && cs.visibility !== 'hidden' && cs.opacity !== '0'; };
    const blocks = [...document.querySelectorAll('h1,h2,h3,h4,h5,h6,p,li,td,th,dt,dd,blockquote,figcaption,label,button,a,summary,span,div')]
      .filter(el => vis(el) && [...el.childNodes].some(n => n.nodeType === 3 && n.textContent.trim().length > 1))
      .map(el => ({ tag: el.tagName.toLowerCase(), text: el.innerText.replace(/\s+/g, ' ').trim(), raw: el.textContent.replace(/\s+/g, ' ').trim() }));
    return {
      title: document.title, lang: document.documentElement.lang, text: document.body.innerText,
      blocks, headings: [...document.querySelectorAll('h1,h2,h3,h4,h5,h6')].map(h => ({ tag: h.tagName.toLowerCase(), text: h.innerText.trim(), raw: h.textContent.trim() })),
      links: [...document.querySelectorAll('a[href]')].map(a => ({ href: a.getAttribute('href'), text: (a.innerText || a.getAttribute('aria-label') || '').trim() })),
      buttons: [...document.querySelectorAll('button, input[type=submit], [role=button]')].map(b => (b.innerText || b.value || b.getAttribute('aria-label') || '').trim()).filter(Boolean),
      placeholders: [...document.querySelectorAll('[placeholder]')].map(e => e.placeholder),
      imgs: [...document.querySelectorAll('img')].map(i => ({ src: i.currentSrc || i.src, alt: i.getAttribute('alt'), w: i.getBoundingClientRect().width })),
      bgImgs: [...document.querySelectorAll('body *')].map(e => getComputedStyle(e).backgroundImage).filter(b => b.startsWith('url(')).map(b => b.slice(5, -2)),
    };
  });
  const slug = route === '/' ? 'home' : route.replace(/^\/|\/$/g, '').replace(/\//g, '__');
  writeFileSync(`${OUT}/${slug}.txt`, `${d.title}\n${d.text}\n${d.imgs.map(i => i.alt).filter(Boolean).join('\n')}\n`);
  const all = [d.title, ...d.blocks.map(b => b.text), ...d.imgs.map(i => i.alt || ''), ...d.placeholders, ...d.buttons];
  const seen = new Set();
  for (const t of all) {
    if (!t || seen.has(t)) continue; seen.add(t);
    const m = t.match(PLACEHOLDER) || t.match(/\b(TODO|FIXME|TBD|XXX+|NaN)\b/); if (m && !ignoreWords.has(m[0].toLowerCase())) add('Critical', 'placeholder', route, t, `contains "${m[0]}"`);
    const tm = t.match(TEMPLATE); if (tm) add('Critical', 'template-leftover', route, t, `"${tm[0]}" from the template/generator`);
    if (/\p{L}\s*\?/u.test(t) && !/¿/.test(t) && lang(t).es >= 1) add('Low', 'missing-opening-question-mark', route, t, 'in Spanish, questions open with ¿');
    if (/€\s?\d/.test(t)) add('Low', 'euro-before-amount', route, t, 'in Spanish: "100 €" (amount, space, symbol)');
    const l = lang(t); if (!tm && l.n >= 3 && l.en >= 2 && l.en > l.es * 2) add('High', 'leftover-english', route, t, `${l.en} English function words vs ${l.es} Spanish ones`);
  }
  const L = lang(d.text), real = L.en > L.es ? 'en' : 'es';
  if (!d.lang) add('High', 'missing-lang', route, '<html> without lang', `detected content: ${real}`);
  else if (!d.lang.toLowerCase().startsWith(real)) add('High', 'wrong-lang', route, `lang="${d.lang}"`, `the content looks like "${real}" (es:${L.es} / en:${L.en} function words)`);
  for (const h of d.headings) {
    const words = h.text.split(/\s+/).slice(1).filter(w => /^[\p{L}]{4,}$/u.test(w));
    const caps = words.filter(w => /^\p{Lu}\p{Ll}/u.test(w));
    if (words.length >= 2 && caps.length / words.length >= 0.6) add('Medium', 'english-title-case', route, `${h.tag}: ${h.text}`, 'in Spanish only the first word and proper nouns are capitalized');
    if (h.raw.length > 3 && h.raw === h.raw.toUpperCase() && /\p{Lu}{4}/u.test(h.raw)) add('Low', 'uppercase-in-markup', route, `${h.tag}: ${h.raw}`, 'written in capitals in the HTML; use text-transform so screen readers and search engines read the normal text');
  }
  for (const a of d.links) if (GENERIC_LINK.test(a.text)) add('Medium', 'generic-link', route, `"${a.text}" → ${a.href}`, 'the link text should say where it leads');
  const altCount = {};
  for (const i of d.imgs) {
    if (i.alt === null) { add('Low', 'alt-missing', route, i.src, 'no alt attribute (details in qa-accessibility)'); continue; }
    altCount[i.alt] = (altCount[i.alt] || 0) + 1;
    if (/\.(jpe?g|png|webp|avif|gif|svg)$|^(IMG|DSC|PXL|Screenshot|Captura)[_ -]?\d*/i.test(i.alt)) add('High', 'alt-filename', route, `alt="${i.alt}"`, i.src);
    else if (GENERIC_ALT.test(i.alt.trim())) add('Medium', 'alt-generic', route, `alt="${i.alt}"`, i.src);
    else if (/^(imagen|foto|fotografía|image|picture) (de|of)\b/i.test(i.alt)) add('Low', 'alt-redundant', route, `alt="${i.alt}"`, 'drop "imagen de" ("image of")');
    else if (i.alt.length > 150) add('Low', 'alt-too-long', route, `alt of ${i.alt.length} characters`, i.src);
    else { const altLang = lang(i.alt); if (altLang.en >= 2 && altLang.en > altLang.es) add('Medium', 'alt-in-english', route, `alt="${i.alt}"`, i.src); }
  }
  for (const [alt, n] of Object.entries(altCount)) if (n > 2 && alt) add('Low', 'alt-repeated', route, `alt="${alt}" ×${n}`, 'several different images with the same alt');
  for (const src of [...d.imgs.map(i => i.src), ...d.bgImgs]) if (STOCK.test(src) || /shutterstock_|istock|gettyimages|adobestock|freepik/i.test(src)) add('Medium', 'stock-image', route, src, 'confirm the license (and that it is not a hotlinked URL)');
  for (const m of d.text.matchAll(/(?:©|\(c\)|copyright)\s*(?:\d{4}\s*[-–]\s*)?(\d{4})/gi)) if (+m[1] < YEAR) add('Medium', 'outdated-copyright', route, m[0], `year ${m[1]}; use the current year or new Date().getFullYear()`);
  // Contact details: normalized to compare them across pages (Spanish phones: optional +34/0034 and 9 digits)
  for (const m of d.text.matchAll(/(?<![\d/])(?:\+34|0034)?[\s.-]?[6789]\d{1,2}(?:[\s.-]?\d{2,3}){2,3}(?![\d/])/g)) { const n = m[0].replace(/\D/g, '').replace(/^(0034|34)(?=\d{9}$)/, ''); if (n.length === 9) note('phones', n, route); }
  for (const a of d.links) if (/^tel:/i.test(a.href)) { const n = a.href.replace(/\D/g, '').replace(/^(0034|34)(?=\d{9}$)/, ''); note('phones', n, route + ' (tel:)'); if (a.text && /\d{3}/.test(a.text) && a.text.replace(/\D/g, '').slice(-9) !== n.slice(-9)) add('High', 'tel-text-differs-from-link', route, `${a.text} → ${a.href}`, 'the number shown is not the one that gets dialed'); }
  for (const m of d.text.matchAll(/[\w.+-]+@[\w-]+(?:\.[\w-]+)+/g)) note('emails', m[0].toLowerCase(), route);
  for (const a of d.links) if (/^mailto:/i.test(a.href)) note('emails', decodeURIComponent(a.href.slice(7).split('?')[0]).toLowerCase(), route + ' (mailto:)');
  for (const m of d.text.matchAll(/(?:C\/|Calle|Avda\.?|Avenida|Plaza|Pza\.?|Paseo|Ronda|Camino|Carrer|Rúa)\s[^\n·|]{3,60}?\b\d{5}\b(?:\s[\p{L} ]{2,25})?/giu)) note('addresses', m[0].replace(/\s+/g, ' ').trim(), route);
  console.log(`${route}: ${d.text.length} characters · lang="${d.lang}" · ${d.headings.length} headings · ${d.imgs.length} images`);
}
const contactOut = Object.fromEntries(Object.entries(contact).map(([k, v]) => [k, Object.fromEntries(Object.entries(v).map(([val, pages]) => [val, [...pages]]))]));
for (const [k, v] of Object.entries(contactOut)) if (Object.keys(v).length > 1) add('High', `inconsistent-contact-${k}`, '(site)', Object.keys(v).join(' | '), 'more than one different value on the website: confirm which one is correct');
const seen = new Map(), uniq = [];
for (const f of findings) { const k = `${f.type}|${f.evidence}`; if (seen.has(k)) { const g = seen.get(k); if (!g.pages.includes(f.page)) g.pages.push(f.page); } else { const g = { ...f, pages: [f.page] }; delete g.page; seen.set(k, g); uniq.push(g); } }
const byType = uniq.reduce((a, f) => (a[f.type] = (a[f.type] || 0) + 1, a), {});
writeFileSync(`${OUT}/content.json`, JSON.stringify({ base, date: new Date().toISOString(), byType, contact: contactOut, findings: uniq }, null, 1));
console.log(JSON.stringify({ byType, contact: contactOut }, null, 1));
await browser.close();
```

How to read `out/content.json`:

| Type | Why it matters | Sev. |
|---|---|---|
| `placeholder`, `template-leftover` | Filler text or text from the Next/v0/Framer starter visible to the public | Critical |
| `wrong-lang`, `missing-lang` | `lang="en"` on a Spanish website: the screen reader mispronounces it, the browser offers to translate and Google is unsure of the language | High |
| `leftover-english` | Buttons or sentences from the template in English ("Learn more", "Get started") | High |
| `inconsistent-contact-*` | Two different phones, emails or addresses: the customer calls the wrong one. Compare with the official details from step 0 | High |
| `tel-text-differs-from-link` | One number is shown and another one is dialed | High |
| `alt-filename` | `alt="IMG_2034.jpg"`: the screen reader reads the file name | High |
| `outdated-copyright` | © from a past year: makes the website look abandoned | Medium |
| `english-title-case` | "Nuestros Servicios De Diseño": in Spanish only the first word and proper nouns are capitalized | Medium |
| `generic-link` | "click aquí" ("click here"), "leer más" ("read more"): out of context it does not say where it leads (and the Spanish spelling is *clic*, not *click*) | Medium |
| `alt-generic`, `alt-in-english` | `alt="imagen"`, `alt="team photo"` | Medium |
| `stock-image` | Image from a stock library: the license must be confirmed and it must not be hotlinked | Medium |
| `uppercase-in-markup` | "EQUIPO" written in capitals in the HTML: better `uppercase` in CSS | Low |
| `missing-opening-question-mark`, `euro-before-amount` | "Hablamos?" without the opening ¿ (Spanish questions open with ¿ and close with ?); "€100" instead of "100 €" (Spanish puts the symbol after the amount, with a space) | Low |
| `alt-redundant`, `alt-too-long`, `alt-repeated` | "Imagen de…" ("Image of…"), alt longer than 150 characters or the same alt on several different photos | Low |

`alt-missing` is only counted: the details belong to `qa-accessibility`.

## Step 4. Spelling and grammar

```bash
node spellcheck.mjs out --words=Nacar,Figma --out=spelling.json                         # cspell, local
LT_URL=http://localhost:8081/v2/check node spellcheck.mjs out --engine=languagetool --words=Nacar   # own LanguageTool server
```

`spellcheck.mjs`:

```js
// spellcheck.mjs: Spanish spelling and grammar on the .txt files from extract-content.mjs.
// Usage: node spellcheck.mjs <txt-dir> [--engine=cspell|languagetool] [--words=Nacar,Figma] [--out=spelling.json]
//   cspell (default): local and private, spelling only (es-ES dictionary). Requires `npm i cspell @cspell/dict-es-es` in this directory.
//   languagetool: spelling + grammar + style. LT_URL=http://localhost:8081/v2/check (own server) or the public API
//     (https://api.languagetool.org/v2/check: max. 20 requests/min, 75 KB/min and 20 KB per request; the text goes to a third party).
import { readdirSync, readFileSync, writeFileSync } from 'node:fs';
import { execFileSync } from 'node:child_process';
import { join, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';

const [dir, ...rest] = process.argv.slice(2);
const opt = Object.fromEntries(rest.map(a => { const [k, v = ''] = a.slice(2).split('='); return [k, v]; }));
const engine = opt.engine || 'cspell', words = (opt.words || '').split(',').filter(Boolean);
const files = readdirSync(dir).filter(f => f.endsWith('.txt')).map(f => join(dir, f));
const here = dirname(fileURLToPath(import.meta.url)), out = { engine, byWord: {}, issues: [] };

if (engine === 'cspell') {
  const cfg = join(here, 'cspell.qa.json');
  writeFileSync(cfg, JSON.stringify({ version: '0.2', language: 'es,es-ES', import: ['@cspell/dict-es-es/cspell-ext.json'], words: words.flatMap(w => [w, w.toLowerCase()]),
    ignoreRegExpList: ['Urls', 'Email', '/\\b[A-Z0-9]{2,}\\b/g', '/\\+?\\d[\\d .-]{6,}/g'], minWordLength: 3 }));
  let txt = '';
  try { txt = execFileSync(join(here, 'node_modules/.bin/cspell'), ['lint', '--no-progress', '--no-summary', '--show-suggestions', '--no-must-find-files', '-c', cfg, ...files], { encoding: 'utf8', cwd: here }); }
  catch (e) { txt = e.stdout || ''; if (!txt) { console.error(e.message); process.exit(1); } }   // cspell exits with code 1 when it finds errors
  for (const l of txt.split('\n')) {
    const m = l.match(/^(.+?):(\d+):(\d+) - Unknown word \((.+?)\)(?: Suggestions: \[(.*)\])?/);
    if (!m) continue;
    const w = m[4], page = m[1].split('/').pop().replace(/\.txt$/, '');
    const e = (out.byWord[w] ||= { count: 0, pages: [], suggestions: (m[5] || '').split(', ').filter(Boolean).slice(0, 3) });
    e.count++; if (!e.pages.includes(page)) e.pages.push(page);
  }
} else {
  const LT = process.env.LT_URL || 'https://api.languagetool.org/v2/check', pub = /api\.languagetool\.org/.test(LT);
  if (pub) console.error('Warning: the text is sent to the public LanguageTool API. Do not use confidential content without permission.');
  let sent = 0;
  for (const f of files) {
    const page = f.split('/').pop().replace(/\.txt$/, ''), text = readFileSync(f, 'utf8');
    const chunks = []; let cur = '';                                  // chunks of ≤ 15 KB, split on line boundaries
    for (const line of text.split('\n')) { if (Buffer.byteLength(cur + line) > 15000) { chunks.push(cur); cur = ''; } cur += line + '\n'; }
    if (cur.trim()) chunks.push(cur);
    for (const c of chunks) {
      if (pub && sent++) await new Promise(z => setTimeout(z, 13000));   // ≈ 4 requests/min × 15 KB < 75 KB/min
      const body = new URLSearchParams({ text: c, language: 'es', disabledRules: 'WHITESPACE_RULE,UPPERCASE_SENTENCE_START' });
      let j; try { const r = await fetch(LT, { method: 'POST', body }); if (!r.ok) throw new Error(`HTTP ${r.status}`); j = await r.json(); }
      catch (e) { out.issues.push({ page, error: e.message }); continue; }
      for (const m of j.matches || []) {
        const w = c.substr(m.offset, m.length);
        if (words.some(x => x.toLowerCase() === w.toLowerCase())) continue;
        out.issues.push({ page, text: w, context: m.context?.text, message: m.message, rule: m.rule?.id, category: m.rule?.category?.id,
          suggestions: (m.replacements || []).slice(0, 3).map(r => r.value) });
      }
    }
  }
  for (const p of out.issues) if (p.category === 'TYPOS') { const e = (out.byWord[p.text] ||= { count: 0, pages: [], suggestions: p.suggestions }); e.count++; if (!e.pages.includes(p.page)) e.pages.push(p.page); }
}
// A word repeated across many pages is usually a proper noun or a brand term: candidate for the allowlist
const ranked = Object.entries(out.byWord).sort((a, b) => b[1].pages.length - a[1].pages.length || b[1].count - a[1].count);
out.byWord = Object.fromEntries(ranked);
writeFileSync(opt.out || 'spelling.json', JSON.stringify(out, null, 1));
for (const [w, e] of ranked) console.log(`${w} ×${e.count} [${e.pages.join(', ')}] → ${e.suggestions.join(' / ') || '?'}${e.pages.length >= 3 ? '  (proper noun? add it to --words)' : ''}`);
for (const p of out.issues.filter(p => p.category !== 'TYPOS')) console.log(`[${p.category || 'ERROR'}] ${p.page}: "${p.text ?? ''}" ${p.message ?? p.error} → ${(p.suggestions || []).join(' / ')}`);
```

| Option | Detects | Privacy | Limits and requirements |
|---|---|---|---|
| **cspell + @cspell/dict-es-es** (default) | Spelling only (unknown word + suggestions). It does not catch "haber si" (a common misspelling of "a ver si", "let's see if") or agreement errors | Everything local | Node ≥ 22.18. Many false positives with proper nouns and anglicisms: extend `--words` |
| **Local LanguageTool** | Spelling, grammar, commonly confused words (haber/a ver, porque/por qué), punctuation, style | Everything local | Java 17 or later (LanguageTool has required JDK 17 since late 2024, even though the server page still says "8 or later") and the zip from languagetool.org: `java -cp languagetool-server.jar org.languagetool.server.HTTPServer --port 8081`. There are community Docker images (unofficial) |
| **Public LanguageTool API** | The same, without the premium rules | The text is sent to LanguageTool (see their privacy policy). Ask the user for permission if the content is not public | 20 requests/min, 75 KB/min and 20 KB per request per IP; POST only; suggestions for 30 words at most; the page itself discourages automated use. The script splits into 15 KB chunks and waits 13 s between requests |
| **hunspell** (`hunspell -d es_ES -l out/*.txt`) | Spelling only | Local | Needs the `es_ES` dictionary (`hunspell-es` package on Debian/Ubuntu). An alternative if there is no Node |

How to review the output:

- Words that show up on many pages are usually brand names: confirm them and pass them to `--words`.
- English words in `byWord` ("started", "here") confirm the leftover English from step 3.
- Everything the checker flags is reviewed by a person, or by you reading the full sentence in the `.txt`. Do not bulk-fix with the first suggestion.

## Step 5. Editorial review (read by the agent)

Read the `.txt` files in `out/` page by page and note, with the exact sentence and the route:

- **Tone and form of address**: *tú* or *usted* across the whole website; the same register in buttons, errors and visible legal texts.
- **Capitalization** (Spanish academic norm, RAE, the Royal Spanish Academy): titles and headings use sentence case, with a capital only on the first word and proper nouns; months and days of the week are lowercase ("octubre", "lunes"); capital letters keep their accent ("ÁREA", not "AREA").
- **Button microcopy**: verb + object that says what happens ("Enviar mensaje" = "Send message", "Descargar catálogo (PDF, 2 MB)"), not a bare "Enviar", "Submit" or "Click". The same verb for the same action across the website.
- **Error messages and empty states**: what happened and what the user can do ("No hemos podido enviar tu mensaje. Inténtalo de nuevo o llámanos al…"). No technical codes and no English. Trigger the errors with `forms.mjs` from `qa-functionality` to read them.
- **Dates, times and numbers** in Spanish format: "26 de octubre de 2026" or "26/10/2026", opening hours in 24 h format ("de 9:00 a 18:00"), "1.250,50 €" (dot for thousands, comma for decimals, symbol after the amount), grouped phone numbers ("910 000 000").
- **Expired dates**: "Próximo evento: marzo de 2024" ("Next event: March 2024"), expired offers, "nuevo" ("new") on something from years ago.
- **Consistency with Figma or the approved document**: texts that were cut, changed or invented by the AI (figures, years of experience, clients, awards). Ask about anything that is not in the source of truth: it is the most serious risk of generated content.
- **Opening hours and social networks**: the hours match the official ones; the social icons point to the company's profiles, not to bare `facebook.com`.

## Step 6. Images and licenses (manual review)

The script only flags URLs and file names from stock libraries. For each relevant image (hero, team, projects):

1. Ask where it comes from: own photo, stock library (with what license and in whose name), generated with AI (with which tool and terms) or taken from the Figma file without knowing its origin.
2. If there is no proof, run a reverse image search (Google Lens or TinEye) and note where it comes from.
3. Photos of recognizable people that are not stock need authorization; "team" photos using stock models can mislead the visitor.
4. Images served from the library's domain (`images.unsplash.com`, etc.) are downloaded, optimized and served from the website.

No proof of license is **High**: it does not block anything technically, but it is a legal risk for the client.

## Severity

| Level | Examples in this phase |
|---|---|
| **Critical** | Visible lorem ipsum, TODO or template leftovers; data invented by the AI (figures, clients, testimonials); wrong contact phone or email on every page |
| **High** | Phones, emails or addresses that differ between pages; wrong `lang`; buttons or sentences in English; spelling mistakes in headlines and CTAs; alt with a file name; images without a proven license |
| **Medium** | Outdated ©; English-style title capitalization; "click aquí"/"leer más"; generic or English alt; mistakes in body text; mixed *tú* and *usted*; unclear error messages |
| **Low** | Capitals written in the HTML; missing ¿ or ¡; number, date or currency format; redundant or overly long alt |

## False positives and limitations

- Language detection uses function words: very short sentences or sentences with many proper nouns can fail. Review `leftover-english` findings shorter than five words.
- `english-title-case` also fires on titles that chain proper nouns or brands ("Nacar Design en Madrid"): review them by hand.
- `example.com`, "Acme" or "TODO" can be legitimate content on a technical website: use `--ignore-words`.
- The address regex only recognizes streets with a five-digit postal code; the phone regex, nine-digit Spanish numbers. Adjust them for other countries.
- The browser's native validation messages come out in the browser's language: they are not leftover English.
- Text that only appears after an interaction (closed accordions, tabs, modals, form errors) is not always in the `.txt`: open them or review the code (step 2).

## If the user asks for fixes

1. Placeholders, template text and AI inventions: do not fill them with invented text; ask the client for the copy and leave the list of pending items.
2. Contact details: centralize them in a single module (`lib/site.ts` with `telefono`, `email`, `direccion`) and use it in the header, footer, contact page and JSON-LD, so they do not diverge again.
3. `lang="es"` in `app/layout.tsx` (or `lang={params.lang}` with i18n).
4. Copyright year: with `cacheComponents: true` (Next 16), `new Date()` in a Server Component **breaks the build** ("encountered the unstable value `new Date()` while prerendering"). Use a cached component:

```tsx
// components/Copyright.tsx
import { cacheLife } from "next/cache";

export async function Copyright() {
  "use cache";
  cacheLife("days"); // recomputed at most once a day
  return <>© {new Date().getFullYear()} Nacar Design</>;
}
```

   Without `cacheComponents`, `{new Date().getFullYear()}` in the footer is enough (it is fixed at each build or revalidation).
5. Spelling and capitalization: changes one by one, reviewed. Rerun both scripts when done.
6. To keep it from happening again, propose (without installing) cspell in CI with a `cspell.json` that imports `@cspell/dict-es-es/cspell-ext.json` and the list of brand terms, plus the `rg` from step 2 as a pre-deployment check.
