# QA of AI-generated code

The goal is to answer with evidence: **does the code contain the faults AI agents usually leave behind?** They are not faults exclusive to AI, but they show up much more often, and some (invented packages, APIs from another Next version) a person almost never makes:

| Study | Data |
|---|---|
| Spracklen et al., USENIX Security 2025 (576,000 samples, 16 models) | Non-existent packages in 5.2 % (commercial models) and 21.7 % (open models) of the code; 205,474 distinct invented names; 43 % repeat across all 10 runs of the same prompt, so an attacker can register them (*slopsquatting*) |
| Veracode, GenAI Code Security Report (Jul. 2026) | Only 56 % of tasks produce code without known vulnerabilities; XSS handled correctly in 15 % |
| CodeRabbit (Dec. 2025, 470 PRs) | 1.7× more issues in AI PRs; readability more than 3×, error handling almost 2× |
| GitClear (Feb. 2025, 211 M lines) | Duplicated blocks ×8 in 2024; moved lines (refactoring) drop 39.9 % |
| Sonar (Aug. 2025) | Over 90 % of issues in LLM code are *code smells* (dead, redundant, complex code) |
| Vercel (Jan. 2026) | Without documentation, agents get 53 % of tasks with Next 16 APIs right; with the `AGENTS.md` index, 100 % |

**By default no code is modified**: deliver the report and fix only if the user asks. Tools go in `/tmp/qa-ai-generated-code/`. **Never install a suspicious package "to see what it does"**: `postinstall` scripts run on install.

Overlaps (don't repeat them, refer): accessibility (`div onClick`, `<img>` without alt) → `qa-accessibility`; unused dependencies in detail, bundle and dead exports → `qa-code-optimization`; secrets, dependency vulnerabilities and headers → `qa-security`; hex and arbitrary values → `qa-design-tokens`; resemblance to the design → `qa-figma-fidelity`.

## Step 0. Context

1. **Next and React version** (`package.json`): the rules are written for Next 16 and React 19. In Next 15, `middleware.ts` is still the convention and synchronous access to `cookies()` or `params` works with a warning: lower the severity of those rules.
2. **Router**: `app/`, `pages/` or both.
3. **Which agent generated it** and whether there is an `AGENTS.md`, `CLAUDE.md` or `.cursor/rules`. Next 16 creates an `AGENTS.md` that tells the agent to read `node_modules/next/dist/docs/`; if it doesn't exist or was deleted, the agent wrote from memory and Next 13–15 APIs are more likely.
4. **History**: `git log --oneline | head -50` and `git log --diff-filter=A --name-only` help to see iterations (files created and abandoned).
5. **ripgrep**: the commands use `rg`. If it is not installed (`rg --version`), `brew install ripgrep` or replace `rg --files …` with `git ls-files -co --exclude-standard` and `rg -n` with `grep -rnE`.

## Step 1. Prepare the tools

```bash
mkdir -p /tmp/qa-ai-generated-code && cd /tmp/qa-ai-generated-code && npm init -y >/dev/null && npm i typescript@5 >/dev/null
```

`typescript@5` is only used by `markup.mjs` (version 7, already published, is the native rewrite and does not offer the same JavaScript API). Write the four scripts there. Tested with Node 22, ripgrep 14 and TypeScript 5.9. Run them from the project root.

How to read it:

- **DOES NOT EXIST** (404): the agent invented it. Critical even if the build passes locally (it may be in the `node_modules` of another branch). If someone registers that name, the next `npm install` installs their code.
- **security holding package** (`0.0.1-security`): npm pulled it as malicious. Critical: check in `package-lock.json` which version got installed and tell the user to rotate credentials if it ran.
- **Reserved / placeholder package**: someone registered the hallucinated name to protect it (real case: `react-codeshift`, a conflation of `react` and `jscodeshift`); the code that imports it does not work.
- **Name similar** to a popular package (edit distance, separators, `react-` + known name conflation): typosquatting or hallucination. Compare by hand on npmjs.com: publisher, repository, date.
- **Created less than 90 days ago** or **fewer than 1,000 downloads/week**: not a fault in itself; it requires looking at the repository, maintainers and code before accepting it. A new official package (e.g. `@tailwindcss/turbopack`) comes out with low severity if it already has many downloads.
- **Not imported in any file or script**: installed "just in case". Confirm it with `npx knip` before proposing to remove it (detailed in `qa-code-optimization`).
- `samePurpose`: two libraries for the same thing (`moment` + `dayjs`, `clsx` + `classnames`): the agent solved the same problem two ways in two sessions.
- `resolvedOutsideRegistry` and "not from the registry": git or URL dependencies, without the registry's version control.
- No lockfile: each install may bring different versions.

Also, with the user's permission: `npm audit signatures` (signatures and provenance of what is installed) and, optionally, the Socket CLI (`npx socket`, requires an account). Known vulnerabilities (`npm audit`) belong to `qa-security`.

```js
];

  lines.forEach((line, i) => { for (const [rule, sev, re, cond, why] of R) {
    if (cond && !cond(file, src)) continue;

  // "use client" with nothing that needs it

  // params without await in pages/layouts/routes (Next 15+ they are a Promise)
  if (APP.test(file) && /(page|layout|route|default)\.[jt]sx?$/.test(file) && /\bparams\.\w+|searchParams\.\w+/.test(src) && !/await\s+(props\.)?(params|searchParams)|use\(\s*(props\.)?(params|searchParams)/.test(src))

  // Test without assertions
  if (TEST.test(file) && /\b(it|test)\(/.test(src) && !/expect\(|assert|toHave|toMatch|\.should/.test(src)) emit({ rule: 'test-without-assertions', sev: 'high', file, line: 1, text: '', why: 'the test always passes' });
}

for (const f of ['middleware.ts', 'middleware.js', 'src/middleware.ts', 'src/middleware.js']) if (existsSync(f)) emit({ rule: 'middleware-renamed', sev: 'medium', file: f, line: 1, text: f, why: 'Next 16 renames it to proxy.ts (keep middleware only if it needs the edge runtime)' });
if (hasPages && hasApp) emit({ rule: 'pages-and-app-mixed', sev: 'high', file: 'pages/ + app/', line: 0, text: '', why: 'two routers at once: duplicated layouts, data and metadata (valid only during a planned migration)' });
console.error(JSON.stringify({ files: files.length, byRule: counts }, null, 1));
```

The most important part of each group:

- **Patterns from another Next version** (agents mix what they learned from Next 12–15): `next/head`, `getServerSideProps` or `next/router` inside `app/` don't break the build in every case, but **they do nothing**; synchronous `cookies().get()`, `params.slug` without `await`, `middleware.ts`, `experimental.ppr`/`dynamicIO`, `next lint`, `serverRuntimeConfig`, AMP and `legacyBehavior` are Next 15/16 changes the agent doesn't know about if it didn't read the bundled documentation.
- **React 19**: `ReactDOM.render`, `defaultProps` on function components, `useFormState` (now `useActionState`).
- **Agent leftovers**: comments addressed to the chat ("// ... rest of the code", "In a real app…", "You can add…"), blocks of commented-out code, `TODO`, mocks and filler content (`mockProjects`, "Acme", lorem ipsum).
- **Silencing instead of fixing**: `any`, file-level `@ts-ignore` and `eslint-disable`, and `catch {}` / `.catch(() => null)`. The last one is the most harmful pattern: if a form submits and discards the error, a failed submission is lost without anyone knowing.
- **Decorative tests**: `expect(true).toBe(true)`, tests without assertions, forgotten `.skip`/`.only`.
- `literal-secret` is flagged so it isn't lost, but the full analysis belongs to `qa-security`.

Confirm with the project's own tools (without changing their configuration): `npx tsc --noEmit` and `npx eslint .` (`eslint-config-next` brings `@next/next/no-img-element` and `no-html-link-for-pages`).

`structure.mjs`:

```js
// structure.mjs: orphaned files (not reachable from Next routes), iteration names (Old, Copy, v2, final…),
// duplicated or near-duplicated files (shingles + Jaccard) and components with the same name in several files.
// Usage (from the root): rg --files -g '!node_modules' -g '!.next' -g '!out' -g '!public' . | node structure.mjs [jaccardThreshold=0.5] > structure.json
import { readFileSync, existsSync } from 'node:fs';
import { dirname, join, normalize, basename } from 'node:path';
import { createHash } from 'node:crypto';

const THR = Number(process.argv[2] || 0.5), CONT = 0.75;   // Jaccard or containment (the small file fits almost entirely in the big one)
const all = readFileSync(0, 'utf8').split('\n').map(s => normalize(s.trim())).filter(f => f && f !== '.');
const code = all.filter(f => /\.(m?[jt]sx?|cjs)$/.test(f) && !/\.d\.ts$/.test(f));
const TEST = /\.(test|spec|stories)\.[jt]sx?$|__tests__\/|(^|\/)(e2e|tests?)\//;
const ENTRY = /(^|\/)(src\/)?app\/.*(page|layout|template|loading|error|global-error|not-found|forbidden|unauthorized|default|route|opengraph-image|twitter-image|icon|apple-icon|sitemap|robots|manifest)\.[jt]sx?$|(^|\/)(src\/)?pages\/|^(src\/)?(proxy|middleware|instrumentation|instrumentation-client|mdx-components)\.[jt]s$|(^|\/)[\w.-]+\.config\.[cm]?[jt]s$/;

// tsconfig/jsconfig aliases ("@/*": ["./*"])
let paths = { '@/*': ['./*'] };
for (const c of ['tsconfig.json', 'jsconfig.json']) if (existsSync(c)) try {
  const j = JSON.parse(readFileSync(c, 'utf8').replace(/\/\*[\s\S]*?\*\/|(?<![:"'])\/\/.*$/gm, '').replace(/,(\s*[}\]])/g, '$1'));
  if (j.compilerOptions?.paths) paths = j.compilerOptions.paths; } catch {}
const EXT = ['', '.ts', '.tsx', '.js', '.jsx', '.mjs', '/index.ts', '/index.tsx', '/index.js', '/index.jsx'];
const set = new Set(code);
const resolve = (from, spec) => {
  let bases = [];
  if (spec.startsWith('.')) bases = [join(dirname(from), spec)];
  else for (const [a, targets] of Object.entries(paths)) { const pre = a.replace(/\*$/, ''); if (spec.startsWith(pre)) bases.push(...targets.map(t => join(t.replace(/\*$/, ''), spec.slice(pre.length)))); }
  for (const b of bases) for (const e of EXT) { const p = normalize(b + e); if (set.has(p)) return p; }
  return null;
};
const src = Object.fromEntries(code.map(f => { try { return [f, readFileSync(f, 'utf8')]; } catch { return [f, '']; } }));
const imports = f => [...src[f].matchAll(/(?:from\s+|import\s*\(\s*|require\(\s*|import\s+)['"]([^'"]+)['"]/g)].map(m => resolve(f, m[1])).filter(Boolean);

const walk = starts => { const seen = new Set(), stack = [...starts]; while (stack.length) { const f = stack.pop(); if (seen.has(f)) continue; seen.add(f); stack.push(...imports(f)); } return seen; };
const prod = walk(code.filter(f => ENTRY.test(f))), withTests = walk(code.filter(f => ENTRY.test(f) || TEST.test(f)));
const orphans = code.filter(f => !withTests.has(f) && !TEST.test(f) && !/(^|\/)scripts?\//.test(f));
const testsOnly = code.filter(f => withTests.has(f) && !prod.has(f) && !TEST.test(f));

const ITER = /(?:^|[-_.\s])(old|copy|backup|bak|new|final|temp|tmp|orig|draft|unused|deprecated|v\d+|\d)$|(?:Old|Copy|Backup|Bak|New|Final|Temp|Tmp|Orig|Draft|Unused|V\d+|\d)$|\s\(\d+\)$/;
const iterations = all.filter(f => ITER.test(basename(f).replace(/\.[^.]+$/, '').replace(/\.(test|spec|module)$/, '')) && !/^(page|layout|route)$/.test(basename(f).split('.')[0]));

// Duplicates: exact hash and normalized 4-token shingles (no comments; hex, numbers and the component's own name neutralized)
const tok = s => { const n = (s.match(/export\s+(?:default\s+)?(?:async\s+)?function\s+(\w+)/) || [])[1];
  let t = s.replace(/\/\*[\s\S]*?\*\/|\/\/.*$/gm, '').replace(/#[0-9a-fA-F]{3,8}\b/g, '#H').replace(/\d+(\.\d+)?/g, 'N'); if (n) t = t.split(n).join('COMP');
  return t.split(/[^\w#[\]-]+/).filter(Boolean); };
const sh = f => { const t = tok(src[f]), out = new Set(); for (let i = 0; i + 4 <= t.length; i++) out.add(t.slice(i, i + 4).join(' ')); return out; };
const cands = code.filter(f => /\.[jt]sx?$/.test(f) && !TEST.test(f) && tok(src[f]).length >= 15).slice(0, 600);
const S = Object.fromEntries(cands.map(f => [f, sh(f)])), H = {};
for (const f of cands) (H[createHash('sha1').update(tok(src[f]).join(' ')).digest('hex')] ||= []).push(f);
const duplicates = [];
for (let i = 0; i < cands.length; i++) for (let j = i + 1; j < cands.length; j++) {
  const a = S[cands[i]], b = S[cands[j]]; if (a.size < 10 || b.size < 10) continue;
  let inter = 0; for (const x of a) if (b.has(x)) inter++;
  const jac = inter / (a.size + b.size - inter), cont = inter / Math.min(a.size, b.size);
  if (jac >= THR || cont >= CONT) duplicates.push({ a: cands[i], b: cands[j], jaccard: +jac.toFixed(2), containment: +cont.toFixed(2) });
}
const names = {}; for (const f of code) for (const m of src[f].matchAll(/export\s+(?:default\s+)?(?:async\s+)?function\s+([A-Z]\w*)|export\s+const\s+([A-Z]\w*)\s*=\s*\(/g)) (names[m[1] || m[2]] ||= []).push(f);
const sameName = Object.entries(names).filter(([n, l]) => new Set(l).size > 1 && !/^(Page|Layout|RootLayout|Home|Loading|Error|NotFound|Template|Default|GET|POST)$/.test(n)).map(([name, files]) => ({ name, files }));

console.log(JSON.stringify({ codeFiles: code.length, orphans, usedOnlyByTests: testsOnly, iterationNames: iterations,
  exactDuplicates: Object.values(H).filter(l => l.length > 1), nearDuplicates: duplicates.sort((x, y) => y.containment - x.containment), sameComponentName: sameName }, null, 1));
```

- `orphans`: not reachable from any route, layout, config or test (it resolves relative paths and `tsconfig` aliases). An orphan with secrets is still a security problem even if it is not imported.
- `iterationNames`: `HeaderCopy`, `Hero-old`, `CardV2`, `page 2.tsx`, `final`: versions the agent left behind while iterating.
- `nearDuplicates`: `containment` ≥ 0.75 = the small file is almost entirely inside the big one (a copy with tweaks). Open them side by side and decide which one stays. `sameComponentName`: two different `Button`s.
- Then look by hand for **different solutions to the same problem**, which the script can't see: data with `fetch` in `useEffect` on one page and in a Server Component on another; one form with a server action and another with `route.ts` + `fetch`; fonts with `next/font` and with `<link>`; styles with Tailwind, CSS Modules and `style={{}}` at the same time. Quick hint: `rg -l "useEffect\(" app components | xargs rg -l "fetch\("`.

`markup.mjs`:

```js
// markup.mjs: "div soup" and Figma leftovers in JSX (TypeScript AST): div/span ratio, div nesting, wrappers with no function,
// div/span with onClick, position absolute with fixed coordinates and fixed px widths/heights copied from the design.
// Usage (from the root): rg --files -g '!node_modules' -g '!.next' -g '*.tsx' -g '*.jsx' . | node markup.mjs > markup.json
// Requires: npm i typescript@5 in /tmp/qa-ai-generated-code (the TypeScript 5 AST API)
import ts from 'typescript';
import { readFileSync } from 'node:fs';

const files = readFileSync(0, 'utf8').split('\n').map(s => s.trim()).filter(f => /\.[jt]sx$/.test(f) && !/\.(test|spec|stories)\./.test(f));
const SEM = /^(header|nav|main|section|article|aside|footer|h[1-6]|p|ul|ol|li|dl|button|a|form|label|figure|figcaption|table|blockquote|address|time)$/;
const ABS_COORD = /(?:^|\s)(?:-?(?:top|left|right|bottom|inset(?:-[xy])?)-\[-?\d+(?:\.\d+)?px\])/g;
const FIXED = /(?:^|\s)(?:min-|max-)?(w|h)-\[(\d+(?:\.\d+)?)px\]/g;
const out = [], tot = { intrinsic: 0, div: 0, span: 0, semantic: 0 };
for (const file of files) {
  let text; try { text = readFileSync(file, 'utf8'); } catch { continue; }
  const sf = ts.createSourceFile(file, text, ts.ScriptTarget.Latest, true, file.endsWith('x') ? ts.ScriptKind.TSX : ts.ScriptKind.TS);
  const m = { file, intrinsic: 0, div: 0, span: 0, semantic: 0, maxDivDepth: 0, findings: [] };
  const line = n => sf.getLineAndCharacterOfPosition(n.getStart()).line + 1;
  const attrs = el => (el.attributes?.properties || []).filter(ts.isJsxAttribute);
  const attr = (el, name) => attrs(el).find(a => a.name.getText() === name);
  const strVal = a => !a?.initializer ? '' : ts.isStringLiteral(a.initializer) ? a.initializer.text : a.initializer.getText();
  const visit = (node, divDepth) => {
    let d = divDepth;
    if (ts.isJsxElement(node) || ts.isJsxSelfClosingElement(node)) {
      const open = ts.isJsxElement(node) ? node.openingElement : node, tag = open.tagName.getText();
      if (/^[a-z]/.test(tag)) {
        m.intrinsic++; if (tag === 'div') m.div++; if (tag === 'span') m.span++; if (SEM.test(tag)) m.semantic++;
        const cls = strVal(attr(open, 'className')), style = strVal(attr(open, 'style'));
        if (tag === 'div') { d++; m.maxDivDepth = Math.max(m.maxDivDepth, d); }
        if (/^(div|span)$/.test(tag) && attr(open, 'onClick') && !attr(open, 'role')) m.findings.push({ rule: 'clickable-div', sev: 'high', line: line(node), why: 'use button or a (keyboard and screen reader); details in the accessibility audit' });
        if (tag === 'div' && ts.isJsxElement(node) && attrs(open).length === 0 && !open.attributes.properties.length) {
          const kids = node.children.filter(c => !(ts.isJsxText(c) && !c.text.trim()));
          if (kids.length === 1 && (ts.isJsxElement(kids[0]) || ts.isJsxSelfClosingElement(kids[0]))) m.findings.push({ rule: 'pointless-wrapper', sev: 'low', line: line(node), why: 'div without attributes wrapping a single element' });
        }
        const coords = [...cls.matchAll(ABS_COORD)].length + (/position\s*:\s*['"]absolute/.test(style) && /(top|left|right|bottom)\s*:\s*-?\d/.test(style) ? 2 : 0);
        if ((/(^|\s)absolute(\s|$)/.test(cls) || /position\s*:\s*['"]absolute/.test(style)) && coords >= 2) m.findings.push({ rule: 'absolute-with-coordinates', sev: 'high', line: line(node), text: cls.slice(0, 100) || style.slice(0, 100), why: 'absolute position with px coordinates: layout copied from the Figma canvas, breaks when the width changes' });
        for (const f of cls.matchAll(FIXED)) if (Number(f[2]) >= (f[1] === 'w' ? 480 : 400) && !/max-/.test(f[0])) m.findings.push({ rule: 'fixed-size-from-figma', sev: Number(f[2]) >= 1000 ? 'high' : 'medium', line: line(node), text: f[0].trim(), why: 'fixed width/height of the Figma frame: overflows on mobile (use max-w, w-full, aspect-*)' });
        const sw = style.match(/\b(width|height)\s*:\s*['"]?(\d{3,})(px)?\b/); if (sw && Number(sw[2]) >= 480) m.findings.push({ rule: 'fixed-size-from-figma', sev: 'medium', line: line(node), text: sw[0], why: 'fixed size in style' });
        if (/(?:leading|tracking|text)-\[\d+\.\d{2,}px\]/.test(cls)) m.findings.push({ rule: 'figma-decimals', sev: 'low', line: line(node), text: (cls.match(/(?:leading|tracking|text)-\[\d+\.\d{2,}px\]/) || [])[0], why: 'value with decimals exported from Figma: see qa-design-tokens' });
      }
    }
    ts.forEachChild(node, c => visit(c, d));
  };
  visit(sf, 0);
  if (!m.intrinsic) continue;
  m.divRatio = +((m.div + m.span) / m.intrinsic).toFixed(2);
  if (m.div >= 10 && m.divRatio > 0.6 && m.semantic / m.intrinsic < 0.2) m.findings.push({ rule: 'div-soup', sev: 'medium', line: 1, why: `${m.div} div and ${m.span} span out of ${m.intrinsic} elements (${Math.round(m.divRatio * 100)} %), few semantic tags` });
  if (m.maxDivDepth >= 6) m.findings.push({ rule: 'excessive-nesting', sev: 'medium', line: 1, why: `${m.maxDivDepth} nested divs` });
  for (const k of Object.keys(tot)) tot[k] += m[k];
  out.push(m);

  filesWithFindings: out.filter(m => m.findings.length).length }, files: out.filter(m => m.findings.length).sort((a, b) => b.findings.length - a.findings.length), rest: out.filter(m => !m.findings.length).map(m => `${m.file} (${m.div} div / ${m.intrinsic})`) }, null, 1));
```

- `absolute-with-coordinates` (`absolute left-[120px] top-[96px]`): the agent copied each layer's position from the Figma canvas instead of the auto layout. It works at 1440 px and breaks at any other width. High.
- `fixed-size-from-figma` (`w-[1440px]`, `h-[933px]`): the frame size turned into a fixed width; overflows on mobile.
- `div-soup` and `excessive-nesting`: each Figma group turned into a `div`. More DOM, worse accessibility and more fragile CSS. `pointless-wrapper`: a `div` without attributes wrapping a single child; it can be removed.
- `clickable-div`: `div onClick` instead of `button`/`a`. Flagged here because it is typical of AI, but the full assessment belongs to `qa-accessibility`.
- `figma-decimals` (`leading-[22.126px]`): unrounded values from the export; the cleanup is guided by `qa-design-tokens`.

## False positives and limitations

- `deps-check.mjs` needs network access to `registry.npmjs.org`. If `api.npmjs.org` doesn't respond, it takes downloads from the registry search (`downloadsSource`). The search may take a while to index newly published packages.
- Packages used without being imported (PostCSS or ESLint plugins declared in JSON, CLIs in `scripts`, `@types/*`): the script excludes the usual ones; confirm the rest with knip.
- `patterns.mjs` works line by line: it doesn't see an empty `catch` spread over several lines nor a `params` destructured and used further down under another name. `img` in an `opengraph-image.tsx` (Satori) is correct. `mock`/`Acme` in Storybook or tests don't count.
- `structure.mjs`: dynamic imports with a computed path, `next/dynamic` with a template and webpack aliases are not resolved; review the orphans before proposing to delete them.
- `markup.mjs` only sees literal classes and styles (not `cn()` with variables nor CSS Modules). `absolute` with coordinates is legitimate on decorative or overlaid elements: review each case.

## If the user asks for fixes

1. Critical dependencies: remove them with `npm uninstall <package> --ignore-scripts` (updates `package.json` and the lockfile without running scripts) and check the build. If a pulled package got installed, warn the user to rotate credentials.
2. Next APIs: use the official codemods rather than editing by hand (`npx @next/codemod@latest middleware-to-proxy .`, `next-async-request-api`, `remove-experimental-ppr`, `next-lint-to-eslint-cli`, `new-link`); then review the `@next-codemod-error` comments.
3. Swallowed errors, mocks and `@ts-ignore`: one by one, with a test or manual check.
4. Orphans and duplicates: delete only after confirming with knip and with the build.
5. Markup: redo absolute layouts with flex/grid (Figma auto layout) and measure with `qa-figma-fidelity`.
6. Run the four scripts again and compare counts.

So it doesn't happen again: keep the `AGENTS.md` that Next 16 generates, ask the agent not to add dependencies without justifying them, and run `deps-check.mjs` and `patterns.mjs` in CI.
